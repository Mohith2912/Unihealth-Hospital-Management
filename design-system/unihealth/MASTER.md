# UniHealth workspace design

Applied using the UI/UX Pro Max skill. The verified healthcare and analytics matches guide a calm, accessible operations dashboard; the generic landing-page recommendation is intentionally not used for authenticated screens.

## Direction

Minimal enterprise layout, blue navigation and actions, teal availability, amber waiting states, red cancellation and emergency states. Every status includes text. No fabricated activity, testimonials, sample patients, or decorative charts.

## Shared system

- Light surface: `#ffffff`; workspace: `#f4f7fa`; text: `#172b40`; primary: `#215dc9`.
- Dark surface: `#192635`; workspace: `#111b27`; text: `#edf3fa`; primary: `#80b0ff`.
- System sans-serif typography keeps the app usable without external font requests.
- Persistent desktop navigation; collapsible mobile navigation; consistent page titles, refresh control, and primary action.
- Grid cards, restrained borders, 8px spacing rhythm, rounded controls, and SVG icons.
- Visible keyboard focus, explicit labels, native modal focus management, reduced-motion support, and 44px action targets.
- Forms retain entered values on failure and expose field errors. Destructive changes require a review dialog.
- Empty, loading, failure, and populated states use the same layout system.
- Manual refresh and post-save refresh show the latest retrieval time. Shift and visit dates use Asia/Kolkata; stored timestamps use UTC.

## Validation

Browser coverage at 375, 768, 1024, and 1440px. Light and dark screenshots are generated by the browser test suite in ignored `.runtime/screenshots/`. Check real form operations and keyboard controls before changing shared components.
